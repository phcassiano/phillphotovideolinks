# Carrossel "5 motivos pra agendar" · Foco no Pet

7 slides 4:5 (1080×1350) para o Instagram **@foconopet.bsb**. Os slides 1, 2 e 4 são **vídeo** (pets animados com Veo 3.1 + texto em motion graphics); os demais são imagem. O slide 6 usa uma imagem ilustrativa gerada com **Gemini 3.1 Flash Image** (a foto real do golden emoldurada numa sala).

Também existem `slide_1.png`, `slide_2.png` e `slide_4.png` (versão em imagem dos slides de vídeo), caso prefira um carrossel só de fotos.

## Editar e exportar de novo
Textos, cores, data e contatos ficam no topo de `build.py`.
```bash
npm install          # uma vez
npm run export       # gera carrossel.html (prévia) e os arquivos em out/
```
